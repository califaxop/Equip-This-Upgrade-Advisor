# Gearsight: Upgrade Advisor

**Which gear is better for you, at a glance.**

Gearsight scores gear for your class and spec, marks upgrades on item tooltips, and glows the best quest reward so you never have to guess.

## Highlights
- **Quest rewards:** the best upgrade among the choices glows. No upgrade? The one that sells for most gets a coin.
- **Tooltips:** "Upgrade +12% (Elemental)", "Downgrade", "Equipped" or "Can't use it", compared with what you wear.
- **Your spec:** picked from your talents, or set it yourself. Every class and spec has stat weights, which you can tune.
- **Smart comparisons:** rings and trinkets against your weaker one, two-handers against main hand + off hand.

## Quick start
1. Install and play: Gearsight works out of the box.
2. Type `/gsight` to check your spec and tune the weights.

## Commands
| Command | Does |
|---|---|
| `/gsight` | Open settings |
| `/gsight item <item>` | How an item was scored (shift-click it into the command) |
| `/gsight spec` | Which spec gear is scored for |

## Good to know
- Stat weights are a starting point, not a simulation: tune them in `/gsight` to taste.
- Equip-line stats (crit, hit, spell damage, mp5) are read from English item tooltips.
